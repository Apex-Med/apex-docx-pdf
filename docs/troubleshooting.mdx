# Troubleshooting

## The engine says locale or time zone is required

Every render must include both fields:

```ts
{ locale: "en-ZA", timeZone: "Africa/Johannesburg" }
```

The engine deliberately refuses to read ambient runtime defaults.

## A value is missing or has the wrong type

Check the compiled manifest and generated JSON Schema, then ensure every required dotted path exists. `number` requires a finite number, `boolean` requires a boolean, and `string`/`date` require strings. See [template language](/template-language).

## A block tag or image tag is rejected

Conditions, loops, and images are planned features. Replace them with a supported inline value tag or redesign the template until the corresponding feature lands.

## The PDF has a Helvetica warning

The engine was created without `FontConfiguration`, so it is using the historical built-in Helvetica/WinAnsi fallback. Supply the exact required TrueType faces in the engine's `fonts` option. Do not expect system-font discovery. See [font handling](/font-handling).

## Font shaping or embedding fails

Confirm that the text is well-formed left-to-right Latin, the selected face contains every required glyph, and the fallback family includes a 400 normal face. OpenType/CFF can be parsed but is not supported for PDF embedding. The default provider embeds a complete TrueType program; it is not a true subsetter.

## Tabs or pagination controls are diagnosed

Tabs require tab-stop layout and are unsupported. Keep-with-next and widow/orphan controls are also outside the current profile; redesign the affected paragraphs rather than assuming Word-equivalent pagination.

## Compilation returned diagnostics with errors

`engine.compile()` throws `EngineOperationError` with code `engine/docx` when DOCX validation or normalization fails. Template-language errors do not currently make `compile()` throw: they are returned in `compiled.diagnostics`. Inspect them before rendering. Rendering a compiled template that already contains errors fails and returns no PDF.

## Content is different from Word

Confirm that the template uses only the supported profile. Tables, headers, footers, images, complex scripts, tabs, keep-with-next, and widow/orphan controls are not supported. Supported style cascades and direct formatting are described in the [feature matrix](/supported-features).

## The browser client cannot render after a reload

Compiled templates live in the worker’s in-memory map. Compile the DOCX again after the worker is disposed, the page reloads, or the client reports `browser/template-missing`.

## The renderer stopped due to a limit

Inspect the diagnostic/error and decide whether the input should be rejected or whether an application-owned engine instance needs a deliberately reviewed `limits` override. Do not lift limits globally as a workaround for untrusted input.
