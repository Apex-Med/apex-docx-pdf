## A useful renderer report

Include:

- engine version and runtime;
- a minimal redistributable DOCX, preferably synthetic and free of confidential data;
- the smallest JSON payload that reproduces the behavior;
- explicit locale, time zone, fonts, limits, and render options;
- diagnostics and the relevant source location;
- whether the concern is semantic output, layout, searchable text, or byte determinism.

Do not attach real patient, client, employee, or financial documents. Rebuild the structure with synthetic text and assets first.

## Feature requests

Check the [support matrix](/supported-features) before opening a request. Unsupported Word features are intentional compatibility boundaries until parser, semantic model, layout, PDF output, fixtures, and documentation can move together. A request is stronger when it includes a small authoring example and explains the required output rather than assuming complete Microsoft Word fidelity.
