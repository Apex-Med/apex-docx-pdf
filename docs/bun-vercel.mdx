# Bun and Vercel

This repository is a Bun workspace monorepo. Its current scripts live at the repository root and in `apps/web`.

## Local commands

```bash
bun test
bun run typecheck
bun run build
bun --cwd apps/web dev
```

The web app uses the browser package and a module worker. The engine packages, including the explicit fontkit adapter, are intentionally portable across Bun, supported Node.js, and modern browsers within the documented compatibility profile. The worker installer accepts explicit engine options, including caller-supplied font bytes; loading bundled application assets into those bytes remains outside the renderer.

## Vercel status

Vercel deployment is planned. This repository does not currently include Vercel project configuration, environment variables, deployment scripts, production domains, or a hosted playground URL.

When deployment is introduced, keep the renderer’s explicit-input contract intact: package bytes and data should reach an application-owned endpoint or worker boundary; locale, time zone, metadata, limits, and authorization must be explicit. Do not turn deployment configuration into an implicit source of fonts, locale, clock data, or network template execution.

</Note>
